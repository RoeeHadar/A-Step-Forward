# Learner-experience audit — 13 Aug 2026

Concrete bugs found while reviewing the live product and `apps/web`. The product promise is a **personalized tutor that remembers you**; several surfaces still behave like a generic catalog or a removed “sidebar template” workflow.

Status: **fixed in this change set** (13 Aug 2026). Remaining watch-item: live production still needs a deploy for learners to see the copy/nav fixes.

---

## P0 — Broken personalization / dead instructions

### 1. Agents tell learners to use a Tutor sidebar plan form that no longer exists
After the guided ReAct plan-change flow shipped, the left-side template panel was removed. Baselines, Mentor skills, intent contracts, chat errors, and i18n still say “open the sidebar template / paste עדכון תוכנית לימוד”.

**Impact:** Learners cannot follow the instruction. Models contradict themselves (guided flow vs template-only).

### 2. Status questions can still feel like “I don’t know your plan”
Hebrew status asks without `?` were not detected as questions (`\b` is ASCII-only). Combined with leftover template protocol, the tutor asked for the program name instead of reading the injected plan.

**Impact:** The opposite of “agents that remember you.” (Partial fix already in chat route; remaining template copy still undermines it.)

### 3. Teaching turns dropped persona / notes
Ordinary math/physics turns skipped durable memory so every student got the same Socratic + short reply. (Fix already in chat context needs; how-to-teach block added.)

### 4. “Due review” practice links ignore `mode=due`
Dashboard/week cards link to `/app/practice?mode=due`, but the page never forwards `mode` and start API hardcodes `queueMode: 'default'`. `/practice` redirect also drops `mode`.

**Impact:** Spaced-repetition CTA does not start a due queue.

## P0 — Navigation friction

### 5. Learn leaves the signed-in app shell
Nav “Learn” goes to `/learn`, which only mounts `SiteHeader`. Sidebar and mobile bar disappear. Students feel ejected from the product.

### 6. Logo sends signed-in learners to marketing home
`brandHref` is `/` for learner shells, abandoning `/app`.

### 7. Hebrew nav: Quiz = «מבחן» next to Tests = «המבחנים שלי»
`/app/quiz` is a custom quiz builder; `/app/tests` is attempt history. Collision sends people to the wrong place.

### 8. Parallel `/lessons` catalog still public
English-only OpenStax demo next to canonical `/learn`. `/app/lessons` already redirects to `/learn`.

### 9. Memory says “you cannot edit” while `/settings/persona` is editable and hidden
No nav link; CLAUDE.md jargon; persona page outside the app shell.
