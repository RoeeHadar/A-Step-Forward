## Design decisions (grilling + resolution)

- **Objective:** maximize P(goal by deadline); plan is living/non-deterministic;
  rolling 2-week horizon; overflow when early, re-pace when behind.
- **Engine:** hybrid — fast deterministic skeleton + async LLM enrichment off the
  critical path.
- **Pacing:** derived per-goal frontier manifest; `required_velocity = remaining ÷
  weeks_left`; `weekly_load = min(capacity, required)`; at-risk when required > capacity.
- **Personalization:** attributes control HOW (session length, load, kind mix, tone),
  not WHAT (selection stays mastery + goal-frontier driven).
- **Potential = adaptive ambition:** core + stretch frontier; ahead → raise ambition,
  behind → protect core. Executed via generated practice (lessons are static).
- **Gate:** competency quiz per week; fail → remediation → soft-override (advance but
  `shaky` + spaced review; blocking only if goal-critical). Threshold relaxes for
  non-critical under deadline pressure.
- **Tests archive:** past tests + learner answers + Reviewer feedback.
- **Spaced review:** ~20–30% weekly capacity via existing Coach FSRS queue.
- Full rationale + resolved parameters in `docs/adr/0009-goal-paced-adaptive-planning.md`.
