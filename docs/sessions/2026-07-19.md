## Design decisions (grilling + resolution)

- **Objective:** maximize P(goal by deadline); plan is living/non-deterministic;
  rolling 2-week horizon; overflow when early, re-pace when behind.
- **Engine:** hybrid — fast deterministic skeleton + async LLM enrichment off the
  critical path.
- **Pacing:** derived per-goal frontier manifest; `required_velocity = remaining ÷
  weeks_left`; `weekly_load = min(capacity, required)`; at-risk when required > capacity.
- **Personalization:** attributes control HOW (session length, load, kind mix, tone),
  not WHAT (selection stays mastery + goal-frontier driven).
- **Potential = adaptive ambition:** core + stretch frontier; ahead → raise ambition,
  behind → protect core. Executed via generated practice (lessons are static).
- **Gate:** competency quiz per week; fail → remediation → soft-override (advance but
  `shaky` + spaced review; blocking only if goal-critical). Threshold relaxes for
  non-critical under deadline pressure.
- **Tests archive:** past tests + learner answers + Reviewer feedback.
- **Spaced review:** ~20–30% weekly capacity via existing Coach FSRS queue.
- Full rationale + resolved parameters in `docs/adr/0009-goal-paced-adaptive-planning.md`.

after each week / after each goal reached, from past history + experience.
- `advanceRollingPlanWindow()` (neon-db.ts) now frontier + pacing driven when the
  goal has a frontier: next week = next UNMASTERED slice of the topo-ordered frontier

### Anchored frontier selection — resolves "start at arithmetic" + first-plan end-to-end
Realized both the rolling re-pace AND a naive frontier-driven first plan would drag an
advanced-goal (5-unit) learner back through `arithmetic`, because the frontier core spans
every prerequisite down to depth 0. This was the exact blocker the team deferred.
- New pure selector `selectNextConcepts()` (plan-pacing.ts): schedule a concept when it is
  FORWARD of the anchor (deepest engaged/mastered frontier concept) OR in the learner's
  engaged set (their entry concepts) OR explicitly weak (remediation). Never-engaged
  far-below foundations are presumed known → skipped. Beginners (no signal) anchor at 0 →
  foundations-first. 6 new unit tests (81 total in pacing+frontier green).
- Wired into BOTH: onboarding first plan (engaged = self-rated set → week 1 is now
  frontier-driven + end-to-end, timeout-safe) AND the rolling advancer (engaged = used∪
  mastered; replaced the raw remaining_ordered slice shipped in d849d490).
- Net: plan is end-to-end from day one, progresses forward to the terminal each advance,
  re-paces from mastery + trailing velocity, and never regresses to elementary material
  for advanced learners. Retires the deferred "baseline mastery seeding" curriculum blocker.
- Verified: tsc ✓ + lint ✓ + 81 unit tests ✓.
