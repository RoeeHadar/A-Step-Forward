# A Step Forward — Dev Vault



Obsidian knowledge base for curriculum intelligence and sub-agent coordination.



**Start here:** [[SETUP|SETUP.md]] — research, MCP config, plugin recommendations, activation checklist.



Quick start:



1. Open this folder as an Obsidian vault

2. Enable MCP **`asf-obsidian`** in Cursor Settings (`Ctrl+Shift+J` → Tools & MCP) — see [[MCP-ENABLE|MCP-ENABLE.md]]

3. Run `node scripts/sync-obsidian-concepts.mjs` and `node scripts/sync-obsidian-expansion.mjs` from repo root

4. Read [[CLAUDE|CLAUDE.md]], [[_active-context|_active-context.md]], and [[curriculum/expansion-dashboard|expansion dashboard]]
