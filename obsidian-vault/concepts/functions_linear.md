# Linear Functions

**HE:** פונקציה לינארית

## Lesson overview

**Lesson:** Linear Functions — Slope, Intercepts, and Lines
**HE:** פונקציות לינאריות — שיפוע, חיתוכים וקווים ישרים

A linear function f(x) = mx + b graphs as a straight line. The slope m measures steepness; b is where the line crosses the y-axis. Two lines are parallel if they have equal slopes and perpendicular if their slopes multiply to −1.

> פונקציה לינארית f(x) = mx + b מצויירת כקו ישר. השיפוע m מודד תלילות; b הוא נקודת החיתוך עם ציר y. שני קווים מקבילים אם השיפועים שלהם שווים, ואנכיים אם מכפלת שיפועיהם היא −1.

- **4pt:** Applications to modeling; deeper parametric analysis
- **5pt:** Tool for tangent lines and linear approximation in calculus
