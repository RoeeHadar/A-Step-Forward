# Hypothesis Testing — Introduction

**HE:** בדיקת השערות — מבוא

## Lesson overview

**Lesson:** Hypothesis Testing
**HE:** בדיקת השערות

Null and alternative hypotheses, test statistics, p-values, significance level, Type I/II errors, one-tailed vs two-tailed tests, and sample-size determination for a desired power.

> השערת אפס ואלטרנטיבה, סטטיסטיקת מבחן, p-value, רמת מובהקות, שגיאות מסוג I/II, מבחנים חד-זנביים ודו-זנביים, וקביעת גודל מדגם לעוצמה רצויה.

- Null hypothesis H₀ vs alternative H₁
- One-tailed vs two-tailed test setup
- Test statistic for sample mean (z)
- Critical value and rejection region
- p-value interpretation
- Type I error (α) and Type II error (β)
- Decision: reject or fail to reject H₀
