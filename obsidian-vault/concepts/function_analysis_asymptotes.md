# Function Analysis — Asymptotes

**HE:** חקירת פונקציה — אסימטוטות

## Lesson overview

**Lesson:** Applications of Derivatives
**HE:** יישומי נגזרות

The derivative is the key to finding maxima, minima, inflection points, and solving optimization problems. Uses $f'$ and $f''$ to analyze function shape.

> הנגזרת היא המפתח למציאת מקסימום, מינימום, נקודות פיתול ובעיות אופטימיזציה. משתמשים ב-$f'$ וב-$f''$ לניתוח צורת הפונקציה.
