# Function Analysis Using Derivatives

**HE:** חקירת פונקציה (ניתוח בעזרת נגזרות)

## Lesson overview

**Lesson:** Applications of Derivatives
**HE:** יישומי נגזרות

The derivative is the key to finding maxima, minima, inflection points, and solving optimization problems. Uses $f'$ and $f''$ to analyze function shape.

> הנגזרת היא המפתח למציאת מקסימום, מינימום, נקודות פיתול ובעיות אופטימיזציה. משתמשים ב-$f'$ וב-$f''$ לניתוח צורת הפונקציה.

## Skill atoms

- Increasing/decreasing intervals: f'(x) > 0 / f'(x) < 0
- Local maximum and minimum: f'(x)=0, sign change test
- Concavity: f''(x) > 0 (concave up) / f''(x) < 0 (concave down)
- Inflection points: f''(x) = 0 and sign change
- Asymptotes: vertical, horizontal, oblique
- Full function investigation (חקירה מלאה)
- Relationship between f(x) and f'(x) graphs
- Relationship between f(x) and f''(x) graphs
- Even/odd function analysis
- Function analysis with parameters
