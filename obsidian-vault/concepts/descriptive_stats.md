# Statistics — Advanced (Normal Distribution)

**HE:** סטטיסטיקה מתקדמת (התפלגות נורמלית)

## Lesson overview

**Lesson:** Descriptive Statistics
**HE:** סטטיסטיקה תיאורית

Mean, median, mode, range, variance, standard deviation, quartiles, IQR, and box plots. Data interpretation and comparison.

> ממוצע, חציון, שכיח, טווח, שונות, סטיית תקן, רבעונים, IQR ותרשים קופסה. פירוש והשוואת נתונים.

## Skill atoms

- Standard deviation: definition and calculation
- Variance
- Normal distribution shape and properties (68-95-99.7 rule)
- z-scores: z = (x-μ)/σ
- Using z-table/standard normal table
- Finding probability from normal distribution
- Finding values given probability (inverse)
